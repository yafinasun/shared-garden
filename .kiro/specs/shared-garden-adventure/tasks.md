# 實作計畫：共享花園冒險版（基準）

已完成的項目記錄目前原型的狀態；未完成的項目是之後要做的事。每項標出對應的需求編號。

## 已完成

- [x] 1. 規則引擎基礎
  - 純函式 `applyAction`、JSON 狀態、存在 state 的亂數種子
  - `createGame`：人數與角色檢查、起始牌組、花園牌堆、盆栽、地球種子
  - _需求：1.1–1.5、16.1–16.4_

- [x] 2. 地圖
  - 6 欄地圖、三選一欄位的戰鬥組合與寶箱／事件、相鄰路線限制
  - 橫向捲動地圖、水彩地點圖示、隨機事件剪影加問號
  - _需求：2.1–2.6_

- [x] 3. 戰鬥
  - 回合流程、病毒意圖、輪流選目標、能量與手牌規則
  - 傷害結算：削弱、減半、護盾、並肩守護、反擊、孢子、核心外殼、淨化因子
  - _需求：3.1–3.7、4.1–4.6、12.1–12.3_

- [x] 4. 勝負與結局
  - 日出結局；任一玩家倒下即失敗
  - 失敗結局：「花園被細菌入侵」背景、全隊倒下圖、依等級縮放的病毒
  - _需求：5.1–5.5_

- [x] 5. 收集卡牌
  - 每人一副戰鬥牌組、專屬牌升階選牌、成熟時強化
  - 戰後每人從 3 張地球植物牌選 1 張
  - _需求：6.1–6.4、7.1–7.6_

- [x] 6. 花園栽培室
  - 照料手牌、休息點恢復、盆栽種植與 4 種盆栽植物效果
  - _需求：8.1–8.6_

- [x] 7. 寶箱、事件、交易
  - 寶箱 2 選、「成長」50% 出現並顯示植物研究者、收穫圖示
  - 5 個事件與事件插圖
  - 植物研究者用 2 個殘骸升級牌卡
  - _需求：9.1–9.8、10.1–10.4、11.1–11.4_

- [x] 8. 介面與音樂
  - 拖拉出牌與點選出牌、資源列水彩圖示、牌卡庫、統一卡牌底框
  - 白柴犬在各畫面縮成約一半；首頁角色疊在植物上層
  - 依場景切換背景音樂與開關
  - _需求：13.1–13.4、14.1–14.5、15.1–15.3_

- [x] 9. 測試工具
  - `dev/adv-sim.html`、`dev/adv-ui.html`、`dev/shot.html`
  - _需求：全部_
